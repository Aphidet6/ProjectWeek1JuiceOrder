## UI icons

The SVG icons use the forest-green theme color and can be loaded with an image tag:

```html
<img src="./images/icons/cart.svg" alt="">
```

Available icons: `cup`, `cart`, `orders`, `settings`, `search`, `user`, `plus`, `minus`, and `close`.
